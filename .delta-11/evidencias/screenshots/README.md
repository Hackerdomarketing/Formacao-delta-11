# Evidências — Screenshots (v5.2 — Regra Inviolável 16)

Pasta canônica para TODO screenshot tirado por agente: prova de estado visual,
evidência de bug, captura pré/pós correção, screenshot de regressão do verify-app.

**Formato:** `[AAAA-MM-DD]/[HHMM]-[tela-ou-contexto]-[AGENTE].png`
Exemplo: `2026-07-03/1430-tela-processando-barra-zero-SCOUT.png`

**Por que existe:** sem endereço canônico, screenshots aterrissam em lugar aleatório
(ou em `/tmp`, onde somem) e a auditoria de "o que estava na tela" fica impossível.

**Retenção:** manual — screenshots são evidência; o GC NÃO apaga esta pasta.
Ao fechar um ciclo, o CRONOS pode arquivar pastas de datas antigas se o comandante aprovar.
